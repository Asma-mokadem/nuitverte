# NuitVerte Mobile

Application mobile Android et backend à microservices (Spring Boot 3, REST, gRPC, SOAP)
pour piloter la recharge nocturne d'un véhicule électrique, protéger la borne des
anomalies du réseau et garantir l'état de charge au départ.

Projet du module Architecture SOA et Services Web, 2026.
